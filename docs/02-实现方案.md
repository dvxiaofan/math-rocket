# math-rocket · 实现方案与任务清单

> 配合 `01-需求与设计.md`。本文是实现依据；完成一项就在清单打勾并写日期。

## 1. 技术栈

- Vue 3 + Vite + TypeScript（与 car-cost-estimator 同套）。
- 状态：Vue `reactive` 单 store（`src/store.ts`），不引 Pinia。
- 动画：CSS transition/keyframes 为主；彩带用 `canvas-confetti`。
- 音效：Web Audio 本地合成（方波/正弦短音），零资源文件。
- 测试：vitest（生成器、评分、自适应）。
- 部署：GitHub Actions → GitHub Pages；`vite.config.ts` 设 `base: '/math-rocket/'`。
- 零 UI 库、零图标库；吉祥物和装饰用内联 SVG。

## 3. 数据模型

```ts
type Level = 1 | 2 | 3 | 4 | 5
type Op = '+' | '-'
interface Question {
  id: string          // "7+5" 规范化后的 key，用于去重
  a: number; b: number; op: Op
  answer: number
  blank: 'result' | 'a' | 'b'   // 缺数题时缺哪个
  level: Level
  choices?: number[]            // 四选一模式下生成
}
interface Attempt { q: Question; input: number; correct: boolean; ms: number }
interface QuizResult {
  at: number; total: number; correct: number; ms: number
  bestStreak: number; levelStart: Level; levelEnd: Level
  wrong: Attempt[]
}
interface Settings {
  count: 10 | 15 | 20          // 默认 10
  mode: 'choice' | 'numpad'    // 默认 choice
  lockLevel: Level | null      // null = 自适应
  sound: boolean
}
```

localStorage 键：`mr.settings`、`mr.history`（最近 30 局）、`mr.level`（推荐档）。

## 4. 核心算法

### 4.1 生成器 `generate(level, exclude: Set<string>, rng): Question`
- 按档位枚举合法 (a, b, op) 组合后随机抽一个（20 以内穷举不到 500 个，直接枚举最稳，不会死循环）。
- 过滤：`b === 0`、`a === b && op === '-'`、已在 exclude。
- L1：op '+'，a,b ∈ [1,9]，a+b ≤ 10。
- L2：op '-'，a ∈ [2,10]，b ∈ [1,a-1]。
- L3：L1 ∪ L2。
- L4：'+'：a,b ∈ [1,19]，a+b ≤ 20 且 (a%10)+(b%10) ≤ 9，且 a+b > 10（和 10 以内的留给 L1）；'-'：a ∈ [11,20]，b ∈ [1,a-1]，a%10 ≥ b%10，且 b < 10。
- L5：'+'：a+b ≤ 20 且 (a%10)+(b%10) ≥ 10，a,b ∈ [2,9]；'-'：a ∈ [11,18]，b ∈ [2,9]，a%10 < b。
- 缺数题：L3+ 且 rng < 0.1 时，`blank` 随机取 'a' 或 'b'，answer 改为被挖掉的数。
- `rng` 注入便于测试（默认 `Math.random`）。

### 4.2 干扰项 `distractors(q): number[]`
- 候选池：answer±1、±2、a+b / a−b 的混淆值、|a−b|、answer 的十位个位对调。
- 过滤 < 0、> 20、等于 answer；去重后随机取 3；不足 3 个时用 answer±3、±4 补。

### 4.3 自适应 `nextLevel(level, streakRight, streakWrong)`
- streakRight ≥ 3 → level+1（封顶 5），清零连对。
- streakWrong ≥ 2 → level−1（保底 1），清零连错。

### 4.4 评分
- 星级：全对 3；错 ≤ 2 题 2；否则 1（按比例换算适配 15/20 题：错误率 ≤ 15% 给 2 星）。

### 4.5 讲解 `explain(q): ExplainStep[]`
返回"画面指令"而不是文字，由 ExplainPanel 渲染：
- `{type:'dots', groups:[a,b], highlight:'count'}`（加法摆点）
- `{type:'dots', groups:[a], cross:b}`（减法划掉）
- `{type:'tenframe', a, b, borrow:3}`（凑十：从 b 里拿 3 给 a）
- `{type:'tenframe-sub', a, b}`（退位：先 10−b，再加个位）
- 附一句 `caption`（≤ 15 字）。

## 5. 视图与交互

- `Quiz.vue` 状态机：`asking → feedback(ok|bad) → (explain) → asking | finished`。
- 四选一点击即判定；数字键盘输入后按「✓」判定，输入位数 ≤ 2。
- 答对 600ms 自动下一题；答错停住，显示正确答案，再弹讲解；讲解「知道了」后下一题。
- 进度条：`RaceTrack` 用 CSS `transform: translateX` 移动小车；跑道按题数分格。
- 吉祥物 mood 由状态机驱动：asking=idle、ok=happy、bad=oops。
- 音效：正确 = 两个上行正弦音（C5→E5 各 80ms）；错误 = 低频方波 150ms；完成 = 三连音。

## 6. 样式系统

- `tokens.css` 定义 §6.2 配色 + `--radius: 22px`、`--tap: 64px`、字号阶梯。
- 布局：`Quiz.vue` 外层 `display:grid`，媒体查询：
  - `(min-width: 900px) and (orientation: landscape)`：`grid-template-columns: 1fr 1fr`。
  - 其余：`grid-template-rows: auto 1fr auto`。
- `html, body { height: 100dvh; overflow: hidden }` 仅在答题视图生效（给 body 加 class）。
- 数字键盘：`aspect-ratio` + `min(…)` 让按键随容器缩放，最小 56px。
- 打印：`PrintSheet.vue` 自带 `@media print`，隐藏导航，A4 两栏 `column-count: 2`。

## 7. 部署

`.github/workflows/deploy.yml`：push main → `npm ci` → `npm test` → `npm run build` → `actions/upload-pages-artifact` → `actions/deploy-pages`。仓库 Settings → Pages → Source 选 GitHub Actions。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| iOS Safari 音频要用户手势后才能播放 | 首页「开始」按钮里初始化 AudioContext |
| 平板浏览器地址栏导致 100vh 跳动 | 用 `100dvh` 并在答题页锁定 overflow |
| 枚举生成器在高档位候选过少 | L4/L5 各 100+ 组合，一局 20 题不会耗尽；仍加兜底：耗尽时放开去重 |
| 讲解动画在低端平板掉帧 | 只用 transform/opacity，元素数 ≤ 20 |
| 6 岁孩子误触设置 | 设置入口做"长按 1 秒"进入 |
