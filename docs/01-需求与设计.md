# math-rocket · 需求与设计

> 版本 v1 · 2026-11-03 · 状态：已确认（赛车主题、默认 10 题、纯前端、GitHub Pages）

## 1. 一句话

给 6 岁左右男孩的加减法练习小游戏：赛车主题、Duolingo 式一题一反馈、每次题目随机生成但难度可控、纯前端、平板横屏和手机都能玩。

## 2. 目标用户与场景

- 使用者：6 岁左右（幼儿园大班～一年级上）男孩，识字量有限，能认 0–20 的数字。
- 陪练者：家长，偶尔看结算页判断孩子薄弱点。
- 设备：家里的安卓平板 / iPad（横屏为主）、家长手机（竖屏）。
- 场景：每天 3–5 分钟，一局 10 题，能自己点着玩，不需要家长读题。

## 3. 范围

做：
- 加法、减法、加减混合；范围 20 以内；五档难度 + 自适应。
- 两种作答方式：四选一、数字键盘。
- 每题即时反馈；错题有动画讲解。
- 结算页：星级、正确数、用时、连击、错题回看。
- 本地历史记录（localStorage）。
- 打印版练习卷（复用生成器，A4 一页）。

不做（v1）：
- 账号、云同步、后端。
- 乘除法、100 以内。
- 语音读题（v2 可用 Web Speech 补）。

## 4. 题目规则

### 4.1 难度档

| 档 | 名称 | 规则 | 示例 |
|---|---|---|---|
| L1 | 10 以内加 | a + b ≤ 10，a,b ≥ 1 | 3 + 4 |
| L2 | 10 以内减 | a ≤ 10，b ≤ a，结果 ≥ 0 | 8 − 5 |
| L3 | 10 以内混合 | L1 + L2 随机 | — |
| L4 | 20 以内不进位/不退位 | 和 ≤ 20 且个位相加不超 9；减法个位够减 | 12 + 5、17 − 4 |
| L5 | 20 以内进位/退位 | 和 ≤ 20 且个位相加 ≥ 10；减法个位不够减 | 7 + 8、15 − 9 |

- L3 及以上，10% 概率出"缺数题"：□ + 3 = 8 / 9 − □ = 4。
- 同一局不出现完全相同的算式；a + b 与 b + a 算同一题。
- 不出 a + 0、a − 0、a − a（太无聊）。

### 4.2 自适应

- 开局档位：上次结算的推荐档；首次为 L1。
- 连对 3 题 → 升一档（最高 L5）；连错 2 题 → 降一档（最低 L1）。
- 结算时给出"下次推荐档" = 本局结束时的档位。
- 家长可在设置里锁定档位（关闭自适应）。

### 4.3 四选一干扰项

- 从 {正确 ±1, ±2, 两个加数之差/之和混淆, 数字对调} 里取 3 个，去重、非负、≤ 20。
- 四个选项随机排序。

## 5. 流程

```
首页 ──开始──▶ 答题页 ×N ──▶ 结算页 ──再来一局──▶ 答题页
  │                                 │
  设置（题数 10/15/20、作答方式、    错题回看 → 讲解面板
       档位锁定、音效开关）
```

### 5.1 首页
- 大按钮「开始比赛」；小按钮：设置、历史、打印。
- 显示当前档位（用赛道等级图标，不写 L1–L5 文字）。

### 5.2 答题页
- 顶部：进度条（赛车沿跑道前进，每答对一题前进一格）+ 连击数。
- 中间：算式大字（≥ 64px）。
- 下方/右侧：作答区（四选一 or 数字键盘）。
- 即时反馈：
  - 对：按钮变绿、叮一声、小车加速动画、连击 +1。
  - 错：按钮变红、正确项高亮、短促"噗"声、弹出讲解面板（可跳过）。
- 不限时，不倒计时（6 岁不加焦虑）。

### 5.3 讲解面板（轻量）
- 只有一个画面 + 一句话，不滚动。
- 加法：先摆 a 个圆点，再摆 b 个，一起数到结果。
- 减法：摆 a 个，划掉 b 个，数剩下的。
- 进位：十格框演示"凑十"（7 + 5：先拿 3 凑成 10，再加 2）。
- 退位：先从 10 里减，再加个位（15 − 9：10 − 9 = 1，1 + 5 = 6）。
- 缺数题：转成对应的加/减法再讲。
- **完全手动**：三步固定，每步停住，点「下一步 ▶」才推进（2026-11-03 用户反馈自动播放太快，改为手动）；最后一步提供「再看一遍」。
- 按钮：「知道了」继续。

### 5.4 结算页
- 星级：10 题全对 3 星；错 1–2 题 2 星；其余 1 星。
- 数据：正确数 / 总数、用时、最长连击、本局档位变化。
- 撒彩带（3 星时更多）。
- 错题列表：点一条打开讲解面板。
- 「再来一局」「回首页」。

### 5.5 打印版
- 从首页进入；选档位和题数（20/30/40）；一页 A4，两栏，留答题横线；页脚写日期和姓名栏。
- 用浏览器打印（`window.print()` + `@media print`）。

## 6. 视觉

### 6.1 主题：赛车
- 氛围：卡通赛道、蓝色赛车（主角）、格子旗、加油站、奖杯。
- 吉祥物：一辆有眼睛的蓝色小赛车，三种表情：等待（眨眼）、答对（笑 + 冒星星）、答错（歪嘴 + 冒烟一下）。

### 6.2 配色（红绿留给反馈，主色不用红）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | `#2F6BFF` 亮蓝 | 主角车、主要按钮 |
| 辅色 | `#FFC23D` 亮黄 | 高亮、星星、奖杯 |
| 强调 | `#FF7A1A` 橙 | 次要按钮、连击 |
| 背景 | `#F4F7FB` 浅灰蓝 | 页面底 |
| 跑道 | `#D9DEE7` 浅灰 + 白色虚线 | 进度条跑道 |
| 文字 | `#1E2A3A` 深蓝灰 | 不用纯黑 |
| 正确 | `#2ECC71` 绿 | 只用于反馈 |
| 错误 | `#FF4D4F` 红 | 只用于反馈 |
| 装饰 | 黑白格子 | 小面积用（旗子、分割线） |

### 6.3 形态
- 圆角 20px+，大阴影，按钮有按下位移。
- 字体：数字用圆体（系统 `ui-rounded` 回退到 `Nunito`/`PingFang`）。
- 所有可点击区域 ≥ 64×64 px。

## 7. 设备适配

| 设备 | 布局 |
|---|---|
| 平板横屏（≥ 900px 宽） | 左：题目 + 吉祥物；右：作答区。两栏各占一半。 |
| 平板竖屏 / 手机竖屏 | 上：进度 + 题目；下：作答区占屏幕下半。 |
| 手机横屏 | 同平板横屏，字号缩一档。 |

- 使用 `100dvh`、`env(safe-area-inset-*)`；答题页禁止滚动、禁双击缩放（`touch-action: manipulation`）。
- 数字键盘 3×4 布局，按键随可用高度等比缩放。
- 验收设备：iPad 1024×768、安卓平板 1280×800、手机 390×844（三种都横竖各试）。

## 8. 非功能

- 纯前端静态站，无后端、无账号、无第三方统计。
- 离线可用（PWA，v1.2 加 service worker）。
- 首屏资源 < 500KB（gzip），无网络字体依赖（字体用系统回退）。
- 音效本地合成或 ≤ 100KB 的短音频，可一键静音。
- 所有文案中文，字数极少；按钮以图标 + 两字为主。

## 9. 验收标准

1. 连续开 20 局，题目不越档、不重复、不出负数、不出 ±0。
2. 平板横屏整页无滚动条，键盘和选项全部可见、可点。
3. 答错必弹讲解，讲解面板一屏内无滚动。
4. 结算页数据与实际作答一致；错题回看能打开对应讲解。
5. GitHub Pages 地址直接打开可玩；刷新不丢设置。
6. 打印版一页 A4 刚好排下 20/30/40 题。
